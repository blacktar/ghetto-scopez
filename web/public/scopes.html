Layout
3D colour cube

Every source pixel contributes. Resolution groups colours into bins; density records pixel counts. Drag to rotate, pinch or wheel to zoom. Uses the measurement level range; values outside it are reported.

Waveform

Source colours tint the luma trace with the mean source hue at each bin. False colour maps signal levels from blue through cyan, green and yellow to red.

Snapshots

Use Snapshot in a scope header to save up to three states. A, B and C toggle red, green and blue overlays independently. A fourth capture replaces the oldest. Controls → Overlay sets opacity. Saved locally in this browser; clearing browser data removes them.
